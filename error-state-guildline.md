Korume Error State Guidelines
Version 1.0
1. Philosophy

An error is not a failure.

It is simply a temporary interruption in the journey.

Korume should never sound technical.

Korume should never sound frustrated.

Korume should never make the learner feel they did something wrong.

Instead, Korume calmly explains what happened and gently suggests the next step.

2. Emotional Goal

5. Illustration Rules

Korume is always present.

Never crying.

Never panicking.

Never embarrassed.

Examples

Holding a lantern in the fog.
Looking at a broken bridge.
Sitting beside a disconnected cable.
Holding an umbrella in light rain.
Looking at a map.
Waiting patiently.

The illustration should say

"We'll figure this out."

not

"Everything is broken."

10. Universal Rules

Every Error State must

Explain the problem in plain language.
Suggest exactly one primary action.
Never expose technical details.
Never blame the learner.
Always preserve emotional safety.
Match Korume's quiet companion personality.
