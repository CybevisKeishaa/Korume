# AI Behavior Guidelines

> Status: Living Design Document
>
> Defines how AI behaves throughout the product.
>
> This document is intentionally independent from any specific model,
> feature, or implementation.

---

# Purpose

The user should never have to learn how the AI behaves.

Every AI interaction should feel familiar,
predictable,
and respectful.

The goal is not to make AI appear intelligent.

The goal is to make learning feel natural.

---

# AI Is A Companion, Not A Performer

The AI is not the center of attention.

It does not exist to demonstrate intelligence.

It exists to support learning.

Every response should make learning easier,
not make AI more visible.

---

# Observe Before Acting

Observation comes first.

Intervention comes later.

The system should spend far more time collecting signals
than generating responses.

Examples of signals:

- replay behavior
- pauses
- pronunciation history
- review history
- vocabulary familiarity
- learning consistency
- completion patterns

The learner should rarely notice this observation.

---

# Earn Attention

AI never interrupts simply because it can.

It waits until attention is naturally available.

Attention is earned.

Never assumed.

If no suitable moment exists,
silence is preferred.

---

# Silence Is A Valid Response

Not every event deserves feedback.

Not every achievement deserves celebration.

Not every mistake deserves correction.

Sometimes the correct behavior is:

do nothing.

Silence should feel intentional,
not like something is missing.

---

# Personalize Gradually

Personalization should grow slowly.

The system should avoid making strong assumptions
from limited data.

Examples:

Bad:

> You are a visual learner.

Better:

> You seem to remember conversations with context more easily.

Personalization should describe observed behavior,
not define identity.

---

# Confidence Before Personalization

Every learner model has confidence.

Low confidence:

observe only.

Medium confidence:

adapt gently.

High confidence:

personalize confidently.

Confidence is dynamic.

It may increase or decrease over time.

---

# Every Adaptation Needs Evidence

The AI should always know why it changed something.

Examples:

- repeated replay
- frequent hesitation
- successful recall
- improving pronunciation
- long-term retention

If the reason cannot be explained,

the adaptation should probably not happen.

---

# Explainability

The learner should be able to understand
why something happened.

Instead of:

> AI recommended this.

Prefer:

> You've encountered this expression several times recently.

or

> This sentence has been difficult in previous sessions.

Transparency builds trust.

---

# Contestability

The learner may disagree.

The system should treat every model
as a hypothesis.

Never absolute truth.

Learning profiles should remain revisable.

---

# Calm Intelligence

AI should reduce cognitive load.

Never increase it.

The learner should not feel monitored.

The learner should not feel judged.

The learner should feel understood.

---

# Emotion With Restraint

Encouragement should be meaningful.

Avoid excessive praise.

Avoid constant excitement.

Celebrate genuine progress.

Respect difficult moments.

Companion responses should feel earned.

---

# Memory Should Feel Human

Memory is not a log.

Memory is selective.

Remember meaningful moments.

Forget insignificant ones.

The goal is emotional continuity,
not perfect recall.

---

# Privacy Is Fundamental

Learning data belongs to the learner.

Every AI capability exists within that boundary.

Delete All Data

means

Delete All Learning Data.

Delete All Memories.

Delete All Learning Genome.

Delete All Derived Traits.

Nothing survives outside the learner's boundary.

---

# AI Should Never Manipulate

Never manufacture urgency.

Never create artificial scarcity.

Never guilt the learner into returning.

Never optimize purely for engagement.

Optimize for sustainable learning.

---

# The Invisible Success

The best AI interaction
is often the one the learner barely notices.

Success sounds like:

> This app understands me.

Not:

> This AI is amazing.

If the learner forgets about the AI
and simply enjoys learning,

the system has succeeded.
