# Interaction Principles

Status: Living Document

Purpose:
Define how every interaction should feel.

---

# Interaction is Conversation

Every click is a question.

Every response is an answer.

Never answer more than the user asked.

---

# Reduce Decisions

Do not ask users what AI can infer.

Do not ask users to organize data AI can organize.

Every unnecessary choice increases friction.

---

# One Primary Action

Every screen should have one obvious next step.

If users hesitate,
the interface failed.

---

# Progressive Disclosure

Simple first.

Details later.

Power should emerge naturally,
never appear all at once.

---

# Respect Momentum

Never interrupt learning.

Never block flow.

Never demand confirmation
unless data could be lost.

---

# Empty States

Empty states should inspire action,
not explain missing data.

---

# Feedback

Immediate.

Calm.

Honest.

Never exaggerated.

---

# Success

Users should feel
"I always knew what to do."
