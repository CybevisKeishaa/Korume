# Design Language

> Status: Living Design Document
>
> Defines how the interface should feel,
> not how individual screens should look.

---

# Design Goal

The interface should disappear.

The learner should focus on Japanese,
not on the application.

Every design decision should reduce friction.

---

# Emotional Direction

The product should feel:

- Calm
- Focused
- Warm
- Quiet
- Confident
- Patient

Never:

- Loud
- Busy
- Hyperactive
- Gamified
- Distracting

---

# The Interface Breathes

Whitespace is not empty space.

Whitespace gives the learner room to think.

Avoid filling every corner.

The interface should feel spacious.

---

# Motion Has Purpose

Animation exists to communicate.

Never to decorate.

Animation should answer questions like:

- Where did this come from?
- Where did it go?
- What changed?
- What deserves attention?

Nothing should move without reason.

---

# Motion Principles

Prefer:

- fade
- gentle scale
- soft slide

Avoid:

- bounce
- shake
- spin
- elastic effects
- exaggerated transitions

Motion should reduce effort,
not attract attention.

---

# Progressive Disclosure

Show only what is needed now.

Reveal complexity gradually.

The interface should feel simple,
even when the system is sophisticated.

---

# Quiet Feedback

Feedback should be subtle.

Examples:

✓ tiny checkmark

✓ soft fade

✓ gentle highlight

✓ small pulse

Avoid:

✗ celebration explosions

✗ flashing badges

✗ aggressive confetti

✗ noisy success screens

---

# Reading First

Japanese content is always the primary focus.

Supporting UI should visually step back.

Typography should create clear hierarchy.

Never compete with learning content.

---

# Consistency Over Novelty

Patterns should repeat.

Interactions should become predictable.

The learner should build intuition over time.

---

# Every Screen Has One Primary Action

Avoid multiple competing calls to action.

If everything is important,

nothing is important.

---

# Calm Progress

Progress should feel continuous.

Not addictive.

The learner should always know:

- where they are
- what they have completed
- what comes next

Without pressure.

---

# Empty States Should Feel Hopeful

Never punish inactivity.

Instead of:

> Nothing here.

Prefer:

> Your journey starts here.

The interface should invite,
never judge.

---

# Color Supports Meaning

Color should communicate.

Not decorate.

Use emphasis sparingly.

If everything is highlighted,

nothing is highlighted.

---

# AI Should Blend Into The Interface

AI should not look like an advertisement.

Avoid large AI banners.

Avoid excessive glowing effects.

AI should feel like part of the product,

not a separate feature.

---

# Accessibility Is Part Of Good Design

Readable typography.

Comfortable spacing.

Clear contrast.

Keyboard accessibility.

Reduced motion support.

Design should welcome everyone.

---

# Less, But Better

When choosing between:

adding

or

removing,

prefer removing.

Complexity should be earned.

Simplicity should be the default.

---

# The Final Test

Before shipping any interface, ask:

Does this help the learner?

Does this reduce cognitive load?

Does this interrupt focus?

Would removing this make the experience better?

If removing it improves the experience,

it probably should not exist.
