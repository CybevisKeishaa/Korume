Empty State Guidelines
Version 1.0
1. Philosophy

Korume never treats an empty state as an error.

An empty state is simply a place where a future memory will begin.

Every empty state should quietly answer three questions:

What is this place?
Why is it empty?
What is the smallest next step?

The goal is never to pressure the learner.

The goal is to invite them.

2. Emotional Goal

Every empty state should make the learner feel

Calm

Safe

Curious

Encouraged

Never Guilty

Never create anxiety.

Never imply failure.

Never use reward psychology.

3. Tone of Voice

Instead of

No lessons.

Nothing found.

No memories.

Empty.

Use

This chapter hasn't begun yet.

Your companion is waiting.

We'll remember this together.

Every journey starts somewhere.

Let's create your first memory.

14. Progressive Empty States

Không phải tất cả Empty State đều giống nhau.

Korume có 3 cấp độ:

Level 1 — First Time
Let's begin.

Dùng khi người dùng chưa từng sử dụng tính năng.

Level 2 — In Progress
You're getting there.

Dùng khi đã có dữ liệu nhưng chưa đủ.

Ví dụ:

Mới học 2 Kanji.
Mới có 1 Conversation Memory.
Mới hoàn thành 10% Journey.

Thay vì hiển thị trống, hiển thị:

"Only a few memories so far. Give it a little more time."

Level 3 — Returning

Khi người dùng lâu không dùng.

Không nói:

You haven't practiced for 30 days.

Mà:

We've been saving this place for you.

Whenever you're ready,
we'll continue.

CTA:

Continue Journey
15. Universal Rules

Every Empty State must:

Feature Korume or a Korume-themed illustration.
Explain what this place is for.
Encourage one clear next action.
Never shame the learner.
Never feel like an error.
Feel like a quiet invitation, not a notification.
Match the emotional tone of the screen (Diary = reflective, Explore = curious, Shadowing = encouraging, etc.).
